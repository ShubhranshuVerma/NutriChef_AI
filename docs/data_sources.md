# Data sources & licenses

Every external dataset must be listed here **before** it is used. Raw data is never committed to git.

| Dataset | Used for | License / terms | Status |
|---|---|---|---|
| RecipeNLG (Bień et al., INLG 2020) | RAG recipe knowledge base, recipe library | **Non-commercial research & educational use only.** Terms must be accepted at download. No redistribution. | Planned (Phase 3) |
| USDA FoodData Central | Nutrient values per 100 g | Public domain (CC0) | Planned (Phase 3) |
| FDA food allergen guidance | Allergen knowledge | U.S. government work (public domain) | Planned (Phase 3) |
| FSSAI labelling & allergen regulations | Indian allergen/diet context | Public regulatory text — cite, summarize | Planned (Phase 3) |
| Indian food values (IFCT 2017, NIN) | Small set of Indian food nutrients | Copyrighted — only limited, cited values | To verify (Phase 3) |
| Price table (₹) | Budget estimates | Own compilation; source + date recorded per row | Planned (Phase 3) |

## RecipeNLG citation

> Bień, M., Gilski, M., Maciejewska, M., Taisner, W., Wiśniewski, D., & Ławrynowicz, A. (2020).
> RecipeNLG: A Cooking Recipes Dataset for Semi-Structured Text Generation. *Proceedings of INLG 2020*, 22–28.
